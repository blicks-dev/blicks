## Description

Heading renders semantic H1-H6 text. Use it for page titles, section titles, card titles, and content hierarchy that should remain meaningful to readers and search engines.

## Controls

### level

Sets the heading level from H1 to H6. Choose the level from document structure first, then style it with typography controls if the visual size needs to differ.

### content

The editable heading text.

## Tips

- Use one H1 for the main page title.
- Do not skip heading levels just to change visual size.
- Use typography controls for alignment, size, weight, and text color overrides.
