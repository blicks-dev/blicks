## Description

Text renders a rich paragraph. Use it for body copy, descriptions, captions, feature text, short notes, and supporting content.

## Controls

### content

The editable paragraph content. Supports inline formatting such as bold, italic, and links.

### tag

The HTML element: a paragraph (default), a div, a span or small print.

### variant

Kept for Text saved before type roles: `lead` draws the Lead style. Kind now writes `typography.role` (body, lead, small, caption) and sets `variant` back to `default`, so the two never disagree. Write the role.

### dropCap

Enlarges the first letter, for an opening paragraph.

## Tips

- Keep Text blocks focused; use multiple Text blocks instead of one long mixed-purpose paragraph.
- Pair Text with Heading inside a stacked Box for consistent content groups.
- Use typography controls for alignment and text styling instead of adding custom classes.
