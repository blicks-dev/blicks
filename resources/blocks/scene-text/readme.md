## Description

Scene text is a text item placed freely on a Scene stage. It carries the full typography, colour and animation controls, plus the Scene item panel that positions it.

## Controls

### content

The editable text. Supports inline formatting such as bold, italic, and links.

### Tag

The heading level used for the document outline and for screen readers. It does not set the visual size — that lives in Typography, so a display headline can read as an H2 without being styled like one.

## Tips

- Drag the item on the canvas to place it; the X and Y fields update as you go and are there for exact numbers.
- A single click still places the cursor, so dragging never gets in the way of editing the words.
- Set the Origin to Centre before centring an item, so its middle lands on the coordinate rather than its top-left corner.
- Give the item an explicit width if you want the text to wrap at a particular measure; without one it sizes to its content.
