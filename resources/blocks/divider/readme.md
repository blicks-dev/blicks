## Description

Divider renders a semantic separator. Use it to separate related content groups, card sections, pricing features, or long page areas.

## Controls

### orientation

Chooses a horizontal or vertical divider.

### thickness

Sets the divider line thickness.

### lineStyle

Chooses the line style: solid, dashed, dotted, or none.

### color

Sets the divider color.

## Tips

- Use Divider when the separation is meaningful, not purely decorative.
- Pair it with spacing so the line has room to breathe.
- Use border tokens for dividers that should match the theme.
