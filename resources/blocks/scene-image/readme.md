## Description

Scene image is an image item placed freely on a Scene stage. It carries the border, effect and animation controls, plus the Scene item panel that positions it.

## Controls

### Alt text

Describes the picture for screen readers and for anyone whose image fails to load. Leave it empty only when the image is purely decorative and the surrounding text already says what it shows.

### Fit

How the picture fills its box when the item is given an explicit width and height. Cover crops to fill, Contain fits the whole picture inside, Fill stretches it.

## Tips

- An item with no explicit size takes the picture's own dimensions, so a dropped image looks like itself before you touch anything.
- Set a width only and the height follows the picture's aspect ratio; Fit matters once you have set both.
- Overlap images by giving them the same coordinates and different z-index values in the Position panel.
- The placeholder is draggable before an image is chosen, so a layout can be composed before the artwork exists.
