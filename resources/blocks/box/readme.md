## Description

Box is the generic styled wrapper for cards, panels, and manual layouts. Use it when Section, Stack, and Grid are too opinionated and you need one element with the full Blicks styling system.

## Controls

### blicks

Stores the full Blicks style tree for layout, spacing, border, position, color, background, typography, and effects controls.

### tag

Chooses the HTML element for the wrapper. Use `div` for generic layout, `article` for repeatable cards, `aside` for supporting content, and `figure` for media groups.

## Tips

- Use Box inside Grid for pricing cards, feature cards, and other repeated panels.
- Use Section for page bands; use Box for the smaller wrappers inside those bands.
