## Description

Menu link is one link for a menu or a column of links: a label, an optional line of description under it, an optional icon before it and a badge such as "New" after it. The whole row is the link, so it is easy to hit on a phone. Use it in mega menu panels, footer columns and sidebars.

## Controls

### label

The link's text. Type it on the canvas.

### description

A short line under the label. Leave it empty for a plain link.

### url

Where the link goes.

### linkTarget

Opens the link in a new tab.

### icon

An optional icon before the label.

### badge

A short tag after the label, such as "New" or "Beta".

## Tips

- Keep descriptions to one short line; a phone menu may hide them.
- Put Menu links in a Box arranged as a stack, with a Heading over them, to make a column of links.
