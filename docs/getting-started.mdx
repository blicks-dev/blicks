Blicks is a free WordPress plugin that adds composable layout and content blocks to the block
editor, all drawing from one design system. This page covers installing it, building a first
section, and where everything lives.

<Note>
Updating a site that already has Blicks 1.x pages? Read [Upgrading from 1.x](/upgrading) first —
2.0 does not carry 1.x layouts over.
</Note>

## Requirements

- WordPress **7.0** or newer (tested up to 7.1)
- PHP **8.1** or newer
- A **block theme** is recommended

<Note>
Blicks also runs on classic themes. With no `theme.json` to sync with, its tokens use Blicks' own
default values.
</Note>

## Try it without installing

Run Blicks in a real WordPress site in your browser. WordPress Playground boots WordPress on
WebAssembly, installs the plugin and opens the editor.

## Install

<Steps>
	<Step title="Search for it">
		In WordPress, go to **Plugins → Add New** and search for **Blicks**.
	</Step>
	<Step title="Install and activate">
		Install it, then activate **Blicks** from the Plugins screen.
	</Step>
	<Step title="Open the editor">
		Open any post or page in the block editor. Every Blicks block is in the **Blicks** category of the inserter.
	</Step>
</Steps>

Updates arrive through WordPress like any other Directory plugin. No build step is needed: the
plugin ships compiled scripts and styles.

To pin a version, or to install without Directory access, download `blicks.zip` from the
[releases page](https://github.com/blicks-dev/blicks/releases) and upload it under
**Plugins → Add New → Upload Plugin**.

## Build a first section

<Steps>
	<Step title="Insert a Section">
		Open the inserter (`+`) and pick **Section**. Choose a starting layout: **Heading + copy** or **Centered hero**.
	</Step>
	<Step title="Edit the words">
		Click into the heading and text and type. Each starting layout puts a stacked **Box** inside the Section to hold them.
	</Step>
	<Step title="Style it">
		Select a block and open the **Style** tab in the sidebar. Pick a size, a fill, corners, a shadow — each section shows its current value on the right.
	</Step>
</Steps>

## The inspector

Every Blicks block has the same sidebar, with three tabs and a menu:

<CardGroup cols={2}>
	<Card title="Settings" icon="settings-2">
		What the block is and does: a Box's **Kind** and **Arrange**, its size, a link, its meaning for screen readers and search engines.
	</Card>
	<Card title="Style" icon="paintbrush">
		How it looks, in sections named for the goal — **Text**, **Fill**, **Border and corners**, **Shadow and depth**, **Space** and **States**.
	</Card>
	<Card title="Motion" icon="sparkles">
		**Entrance** (fade in, rise or zoom as it scrolls into view) and how fast and with what feel hover and click changes play.
	</Card>
	<Card title="More (•••)" icon="ellipsis">
		**Show on** (hide a block on desktop, tablet or phone), **Screen readers**, and **HTML attributes**.
	</Card>
</CardGroup>

<Frame caption="A Box's Settings tab: Kind, Layout, Size, Link and Meaning and access.">
	<img src="/images/inspector/box-1-settings.png" alt="The Settings tab for a Box, showing the Kind cards, the Arrange choices and the Size controls" style={{ maxWidth: '280px' }} />

A section's **Customize ›** opens the finer controls for it in place of the panel. At the bottom of
the Style tab, **All settings** lists every value the block stores — including the ones the quick
choices above cannot show — and lets you search for and add any setting the block allows.

There is no state switcher and no device switcher. Hover, click and focus looks live in
**Style ▸ States**; see [States and interactions](/guides/states-and-interactions). Phone layouts
are switches on the block, such as **Stack on phones**; see
[Responsive patterns](/guides/responsive-patterns).

## Blicks Studio

**Blicks Studio** is a full-screen workspace for composing a section from the pattern library, with
layers, desktop, tablet and phone widths, and a Play button for motion. Open it from the
**Blicks Studio** button in the editor's top bar, from the command palette (**Open Blicks Studio**),
or with **Open in Studio** on a Blicks block's toolbar. Nothing is written to your post until you
leave by **Insert**.

## How the design system works

Blicks keeps its own catalogue of design tokens — colors, spacing, type sizes, corners, shadows and
more — and their values resolve through your active theme's `theme.json` presets. Change your
theme's palette and every Blicks block that uses it follows. Where the theme defines no scale of
its own, Blicks falls back to its own values.

A block stores a token's name, not a copied value. Read the full model in
[Global tokens](/reference/design-system/global-tokens) and
[Type roles](/reference/design-system/type-roles).

## Where things live in the admin

The **Blicks** menu in wp-admin has five screens:

| Screen | What it is for |
|---|---|
| **Overview** | A getting-started checklist, a preview of your design system, recent changes, and health checks |
| **Design System** | Colors, typography, spacing, corners, shadows, motion and the rest, with your site previewed live beside them. See [Customize the design system](/guides/customize-design-system) |
| **Settings** | Global Styles sync, Loop data sources, form spam-check keys, and what happens to your data on delete |
| **MCP** | Turn on AI agent access and connect a client. See [Connect an AI agent](/guides/connect-an-ai-agent) |
| **Entries** | What visitors sent through your forms. See [Forms](/guides/forms) |

<Info>
By default, deleting the plugin removes nothing. Your design system, settings and form entries
survive a delete and reinstall unless you set **When Blicks is deleted** to **Remove everything** in
**Blicks → Settings** first.
</Info>
