Every Blicks block draws from one set of design tokens. Blicks keeps its own catalogue of them,
and their values resolve through your active theme's `theme.json` presets where the theme defines
them. **Blicks ▸ Design System** is where you make them yours.

## The screen

The sidebar groups every token by what it is for:

| Group | Pages |
|---|---|
| **Look and feel** | Design language, Colors, Typography |
| **Layout** | Spacing, Widths and shapes, Screen sizes |
| **Surfaces** | Corners, Shadows, Borders, Buttons, Gradients |
| **Motion** | Transitions, Hover effects, Animations |
| **Advanced** | Transparency, Stacking, Line spacing, Where it's saved |

**Your site, live** on the right redraws a sample page as you change values. Point at a token to
see where it is used. **Find a token** searches by name or by what it is for, such as "button" or
"card".

Changes wait until you choose **Save** at the top, or **Discard**.

## Design language

<Frame caption="Design language, with Kits.">
	<img src="/images/admin/1-look-and-feel-1-look.png" alt="The Design language page with Kits below it" />
</Frame>

A **design language** sets how your site is drawn — corners, depth, borders, headings and surfaces —
as one choice: Minimalism, Flat design, Skeuomorphism, Glassmorphism, Liquid Glass, Neumorphism,
Claymorphism, Neo-brutalism, Bento grid or Retro Y2K. Point at one to try it on the live preview.

Choosing a language changes shared values only, so every page restyles at once and nothing is
re-saved. A color or shape set by hand on a block stays as it was. Your colors are separate, so any
language works with any palette.

## Colors and palettes

Start from a palette, then tune any color. Built-in palettes are **Blicks Indigo**, **Emerald
Citrus**, **Rose Ember**, **Violet Bloom** and **Slate Sky**. Using one repaints your brand colors;
your design language stays.

Every surface color comes paired with the text color that sits on it, and each pair shows whether
people can read it. **Save these colors as a palette** keeps your own set beside the built-in ones.

## Kits

A **kit** is a design language, a palette and your own values, saved together. **Save what you have
now as a kit** to come back to it in one click.

## Typography and type roles

Beyond the font-size scale, Blicks has **type roles** — Display, Heading 1 to 6, Body, Lead, Small,
Caption, Code and Eyebrow / mono. A role bundles a complete look: size, weight, line height, letter
spacing, font and letter case. Edit them under **Typography**. See
[Type roles](/reference/design-system/type-roles).

## Add your own tokens

Colors, spacing, corners, shadows, gradients, transitions, layers, transparency, border widths,
widths and line spacing accept tokens of your own. Add one, name it, give it a value, and it shows up
as a choice in every block control that uses that kind of value.

## Animations

<Frame caption="Motion ▸ Animations.">
	<img src="/images/admin/4-motion-3-anim.png" alt="The Animations page of the Design System screen" />
</Frame>

**Motion ▸ Animations** is a small keyframe editor: **New animation**, a name, a length, a speed
curve, and steps with the properties each one sets. An animation saves as soon as you add it — it
does not wait for the Save button — and becomes selectable for any block's motion.

## Screen sizes

**Layout ▸ Screen sizes** sets where the layout switches to tablet and phone: 782px and 600px by
default. Phone must be narrower than tablet. See [Responsive patterns](/guides/responsive-patterns).

## Global Styles sync

With **Sync with Global Styles** on in **Blicks ▸ Settings**, a save also writes these values into
the Site Editor's Global Styles, so WordPress holds them natively. It is off by default, and
unavailable when the active theme has no `theme.json`.

**Advanced ▸ Where it's saved** shows where your values live.

## Token categories

| Category | Slugs |
|---|---|
| Color | `background`, `foreground`, `primary`, `primary-foreground`, `secondary`, `secondary-foreground`, `muted`, `muted-foreground`, `accent`, `accent-foreground`, `destructive`, `border`, `input`, `ring`, `card`, `card-foreground`, `popover`, `popover-foreground` |
| Spacing | `0`, `px`, `xs`, `sm`, `md`, `lg`, `xl`, `2xl`, `3xl`, `4xl` |
| Font size | `xs`, `sm`, `base`, `lg`, `xl`, `2xl`, `3xl`, `4xl` |
| Font family | `sans`, `serif`, `mono` |
| Radius | `none`, `sm`, `md`, `lg`, `xl`, `full` |
| Shadow | `none`, `sm`, `md`, `lg`, `xl` |
| Gradient | `brand`, `paper`, `atomic`, `backdrop` |
| Transition | `fast`, `base`, `slow` |
| Transform | `lift`, `press`, `zoom` |
| Filter | `blur`, `dim`, `grayscale` |
| Z-index | `base`, `sticky`, `drawer`, `popover`, `drag`, `toast` |
| Opacity | `disabled`, `muted`, `scrim`, `hover` |
| Border width | `hair`, `strong`, `heavy` |
| Width | `prose`, `content`, `wide`, `full` |
| Aspect | `square`, `wide`, `portrait` |
| Line height | `tight`, `snug`, `body`, `loose` |
| Content | `size` |
| Button | `radius`, `height`, `padding-x`, `padding-y`, `font-size`, `font-weight`, `border-width` |

The catalogue ships in the plugin at `resources/design-system/tokens.json`, and PHP reads the same
file, so the editor and the server agree on which slugs exist. See
[Global tokens](/reference/design-system/global-tokens) for how each one maps to CSS.
