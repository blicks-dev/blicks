title: "Build a Landing Page"
description: "Compose a hero, a feature grid and a call to action from Section and Box, with Heading, Text, Buttons and Icon inside."
---

Blicks has a small set of blocks that compose, and one rule that makes them predictable:
**Section owns the band, Box owns the arrangement and the surface, everything else is content.**
This guide builds a three-band landing page with them.

## The mental model

<CardGroup cols={3}>
	<Card title="Section" icon="layout-panel-top">
		The full-width band: an outer `<section>` you style, and an inner wrapper that holds the content to a width.
	</Card>
	<Card title="Box — Arrange" icon="columns-3">
		**Arrange what's inside**: **As written**, **Stacked**, **Side by side**, **Grid** or **Layers**.
	</Card>
	<Card title="Box — Kind" icon="square">
		**What is it?**: **Plain**, **Card**, **Panel**, **Cover**, **Badge**, **Divider** or **Spacer**.
	</Card>
</CardGroup>

Heading, Text, Buttons, Image, Icon and List are the content you put inside. A line or an empty gap
is a Box too: pick **Divider** or **Spacer** under **What is it?** while the Box is empty.

Only a few blocks have a fixed place: a Button lives in Buttons, a List item in a List, a Step in
Steps, and a Field in a Form. Everything else nests freely.

## Band 1 — the hero

<Steps>
	<Step title="Insert a Section">
		Pick **Centered hero** as the starting layout. You get a heading, a line of text and two buttons in a stacked Box, centered.
	</Step>
	<Step title="Set the band's height">
		In the Section's **Settings**, set **Height, at least** to **Most of the screen** or **Full screen**. It is a minimum, so a tall hero on a narrow screen grows instead of clipping.
	</Step>
	<Step title="Space the contents">
		Select the Box. Under **Layout**, pick **Space between**. The Box spaces its children — no Spacers between every item.
	</Step>
	<Step title="Write it">
		Replace the heading, the text and the two button labels. Set each Button's **Look** — **Main** for the first, **Outline** for the second.
	</Step>
</Steps>

<Note>
Section's content width is **Theme** by default: it follows the design system's content size, then
your WordPress theme's, so it lines up with the rest of your site. Change it under
**Settings ▸ Content width** only when this band should be wider or narrower.
</Note>

## Band 2 — the feature grid

<Steps>
	<Step title="A second Section">
		Pick **Heading + copy**, then set the Section's **Surface** to **Muted** for a soft band that separates it from the hero.
	</Step>
	<Step title="Add a Box arranged as a Grid">
		Under **Layout**, choose **Grid**. Set **Columns** to **Fit to width** and **Each at least** to about 280px.
	</Step>
	<Step title="Build one card">
		Inside the grid, add a Box and set **What is it?** to **Card**. Put an Icon, a Heading and a Text in it.
	</Step>
	<Step title="Duplicate it">
		Duplicate the card for each feature. The grid places them.
	</Step>
</Steps>

**Fit to width** is the part worth understanding. The grid fits as many columns as there is room
for and reflows on its own — three across on a desktop, two on a tablet, one on a phone. Choose
**Set number** only when the count is part of the design; phones still get one column unless you
turn off **One column on phones**.

To make a card react to the pointer, open its **Style ▸ States** and pick an **On hover** look such
as **Lift**. See [States and interactions](/guides/states-and-interactions).

## Band 3 — the call to action

A call to action is the hero again, shorter: a Section with a stacked, centered Box holding a
Heading, a Text and Buttons. Give the Section the **Card** surface, or a Box inside it the **Cover**
kind for a big colored band.

To make a whole card clickable rather than just its button, give the Box a **Link** —
**Make the whole box clickable**. The card becomes one link, with a **Link name** for screen
readers, and nothing interactive nests inside another.
