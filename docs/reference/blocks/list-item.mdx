## Help

## Description

One item of a List. It holds its words and, below them, one inner list for the items indented under it.

## Controls

### content

The item's words, with bold, italic, links and the other inline formats.

### state

Normal, Highlight (a soft band behind the item) or Left out (struck through and grayed, with a cross for a marker).

### icon

An icon of its own, in an icon list. Empty uses the list's icon.

### markerColour

A marker color of its own. Empty uses the list's.

## Tips

- Indent and outdent with Tab and Shift+Tab while typing, or with the Level buttons.
