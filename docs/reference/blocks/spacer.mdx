## Help

## Description

Spacer adds intentional empty space. Use it sparingly to create rhythm between sections or to reserve space in utility layouts.

## Controls

### size

Sets the spacer dimension.

### orientation

Chooses whether the spacer creates vertical or horizontal space.

## Tips

- Prefer Section spacing and Stack/Grid gaps before adding Spacer blocks.
- Use Spacer for exceptional layout rhythm, not as the default spacing system.
- Keep spacer values token-like and consistent across a page.
