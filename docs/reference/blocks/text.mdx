Text renders a rich paragraph. Use it for body copy, descriptions, captions, feature text, short notes, and supporting content.

## Tips

- Keep Text blocks focused; use multiple Text blocks instead of one long mixed-purpose paragraph.
- Pair Text with Heading inside Stack for consistent content groups.
- Use typography controls for alignment and text styling instead of adding custom classes.
