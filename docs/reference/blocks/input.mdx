## Help

## Description

Input is the control of a Field: the box, list, choices or tick box a visitor fills in. Every Field has exactly one, and it cannot be removed on its own. What it asks for — its type, name, options, placeholder and rules — is set on the Field; the Input draws it.

## Controls

### icon

An icon drawn inside the control, at its start, for one-line boxes (Short text, Email, Phone, Number, Date, Time) and Dropdowns. Screen readers skip it. A Number drawn as a stepper has none.

## Style

Its Style tab styles the control itself: its fill, text color, border, corners, shadow, spacing, width and height. What you set here wins over the Form's look (filled, outlined or line) for this one control. For Choices it styles each option — the row, chip, card or segment — not the row around them.
