## Help

## Description

Image renders a responsive figure with optional link and caption. Use it for visual content that belongs to the page structure, not for decorative backgrounds.

## Controls

`aspectRatio`, `objectFit` and `width` are the only way to set the picture's shape, fit and width: they style the `<img>` and the figure, so the block does not allow `layout.aspectRatio`, `layout.objectFit` or `layout.width`.

### id

Stores the selected WordPress media ID when an image is chosen from the media library.

### url

The image source URL.

### alt

Alternative text for accessibility.

### aspectRatio

Controls the displayed image ratio. Use `auto` to preserve the natural image dimensions.

### objectFit

Controls how the image fits inside the chosen aspect ratio.

### linkTo

Chooses whether the image links nowhere, to the media file, or to a custom URL.

### href

The custom destination when `linkTo` is set to custom.

### caption

Optional figure caption.

## Tips

- Write alt text for meaningful images; leave it empty only when the image is decorative.
- Use aspect ratio for consistent card and grid layouts.
- Use Background controls on Section or Box for decorative imagery.
