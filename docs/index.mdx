# The atomic WordPress builder, documented from source.

Blicks is a free, GPL-licensed WordPress plugin: **12 composable Gutenberg blocks** on a single
design system that reads your theme's `theme.json` instead of replacing it. These docs are generated
from the monorepo, block metadata, and package Markdown, so the reference stays aligned with the
code that actually ships.

## Update flow

<Steps>
	<Step title="Edit source">
		Update Markdown, block metadata, or per-block readme files in Git.
	</Step>
	<Step title="Generate">
		Run `pnpm docs:generate` and commit the result. Mintlify does not run build scripts, so the block reference is committed to the repo.
	</Step>
	<Step title="Publish">
		Mintlify rebuilds the site from this directory on every push.
	</Step>
</Steps>
