# Atomic blocks for the block editor, documented from source.

Blicks is a free, GPL-2.0-or-later WordPress plugin: composable layout and content blocks on one
design system whose tokens resolve through your theme's `theme.json`. It runs inside the native
block editor. The block reference on this site is generated from the plugin's own block metadata,
so it describes the code that ships.

## The blocks

| Group | Blocks |
|---|---|
| Layout | Section, Box |
| Content | Heading, Text, Image, Icon, Buttons, Button |
| Lists | List, List item, Steps, Step |
| Forms | Form, Field, Input |
| Behavior | Dialog, Loop, Menu link |

Box covers what a layout needs: its **Kind** makes it a card, panel, cover, badge, divider or
spacer, and **Arrange** lays out what is inside — stacked, side by side, in a grid or in layers.

## How these docs are made

<Steps>
	<Step title="Edit source">
		Pages and the per-block readmes live in the plugin repository, beside the code they describe.
	</Step>
	<Step title="Generate">
		`pnpm generate` in `docs/` rebuilds the block reference from each block's `block.json` and readme. The result is committed, because Mintlify does not run build scripts.
	</Step>
	<Step title="Publish">
		Mintlify rebuilds the site from the repository on every push.
	</Step>
</Steps>
